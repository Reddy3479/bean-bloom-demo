# Bean & Bloom Cafe — Portfolio Demo

A responsive static website built with HTML, CSS, and vanilla JavaScript. It is designed to run on an older laptop and does not need Node.js, Python, a database, or a build step.

## Files
- `index.html` — page structure and demo content
- `style.css` — visual design and mobile responsive rules
- `script.js` — mobile navigation and automatic footer year

## Run locally
1. Extract this folder.
2. Open `index.html` in Chrome or Edge.
3. Resize the browser to test the mobile layout.

An internet connection is needed for the remote Unsplash photos and Google Fonts. The rest of the page is local.

## Before using for a real client
- Replace the demo brand name, text, menu, prices, address, and hours.
- Replace the WhatsApp placeholder number in `index.html` with the client's approved number in international format (digits only in the `wa.me` URL).
- Use only photos the client owns or has permission/licence to use.
- Test all links and ask the client to approve the final content.
- Agree in writing on the scope, price, deadline, revision count, domain/hosting costs, and payment milestones before starting.
- Do not promise features that are not implemented (for example, online ordering or table booking).

## Free static hosting with GitHub Pages
1. Create/sign in to a GitHub account only if you meet its current age requirements; if not, ask a parent/guardian to help in a permitted way.
2. Create a new public repository, e.g. `bean-bloom-demo`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for the published URL to appear in the Pages section. Open it and test on phone and laptop.

GitHub Pages is for static sites. This demo does not have a server, database, private admin area, or form-processing backend. Never upload passwords, API keys, private client data, or student records to a public repository.
